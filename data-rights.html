Права субъекта персональных данных

Порядок обращения по вопросам персональных данных в приложении «Дошикология»

Редакция от 9 ноября 2026 года

1. Как связаться с разработчиком

Разработчик приложения — Роман Татабаев. По вопросам обработки персональных данных можно обратиться по электронной почте: romantatabaev@gmail.com.

2. Какие права можно реализовать

Пользователь вправе запросить информацию об обработке его персональных данных, уточнение, исправление, блокирование или удаление сведений, находящихся у разработчика, а также отозвать ранее предоставленное согласие там, где обработка основана на таком согласии. Запрос рассматривается в соответствии с применимым законодательством; некоторые сведения могут подлежать сохранению по закону.

3. Как направить запрос

Отправьте письмо на romantatabaev@gmail.com с темой «Персональные данные — Дошикология». Укажите, какое действие необходимо выполнить и о каких данных идёт речь. Разработчик может запросить дополнительные сведения, необходимые для проверки обоснованности обращения и предотвращения раскрытия данных посторонним. Не присылайте пароли и полные реквизиты банковских карт.

Ответ направляется на адрес, с которого получено обращение, в сроки, установленные применимым законодательством.

4. Данные, хранящиеся на устройстве

Для работы базовых функций приложения не требуется регистрация пользователя. Избранное и загруженные материалы могут храниться локально на устройстве. Чтобы удалить их, можно очистить данные приложения в настройках Android либо данные сайта в браузере. При этом избранное и скачанные рецепты будут удалены.

5. Внешние сервисы и публичные записи

При обращении через электронную почту данные письма обрабатываются для ответа. Добровольная поддержка осуществляется через внешний платёжный сервис CloudTips, который обрабатывает платёжные сведения по собственным правилам. Данные технических сетевых запросов могут обрабатываться инфраструктурой GitHub Pages.

Если на Стене меценатов размещены сведения, относящиеся к вам, вы можете запросить их исправление или удаление по указанному выше адресу.

6. Дополнительная информация

Подробное описание обработки сведений содержится в Политике конфиденциальности. Данный документ дополняет её и предназначен для обращений пользователей по вопросам персональных данных.
