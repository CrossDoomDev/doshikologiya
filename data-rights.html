Удаление персональных данных и права пользователя

Как запросить удаление данных приложения «Дошикология» и какие сведения могут сохраняться

Редакция от 12 ноября 2026 года

1. Как запросить удаление данных

В приложении «Дошикология» нет регистрации и учётных записей. Для запроса на удаление персональных сведений, находящихся у разработчика, не требуется создавать аккаунт или устанавливать приложение повторно.

  1. Отправьте письмо на romantatabaev@gmail.com.
  2. Укажите тему «Удаление данных — Дошикология».
  3. Опишите, какие именно данные требуется удалить: переписку с поддержкой, сведения на Стене меценатов или иную информацию, которую вы ранее предоставляли разработчику. Для поиска сведений можно указать дату обращения или опубликованный псевдоним.
  4. Разработчик при необходимости уточнит информацию, проверит обоснованность запроса и сообщит результат на адрес, с которого поступило обращение.

Не отправляйте паспорт, пароли и полные платёжные реквизиты без отдельной обоснованной необходимости. Для проверки запроса могут потребоваться минимальные дополнительные сведения, чтобы не удалить данные другого человека.

2. Какие данные удаляются по запросу

  • Переписка с поддержкой: сведения из писем и вложений, находящиеся под контролем разработчика, удаляются после выполнения запроса, если отсутствует законное основание для дальнейшего хранения.
  • Стена меценатов: реальные имя или псевдоним, комментарий и связанные сведения в публичной записи могут быть исправлены или удалены из публикуемого разработчиком каталога после проверки принадлежности записи и запроса.
  • Иные предоставленные разработчику данные: рассматриваются по существу обращения в пределах фактического доступа и правовых обязанностей разработчика.

В приложении нет пользовательских аккаунтов и отдельной серверной базы личных профилей; удаление учётной записи не требуется и не предлагается.

3. Какие сведения могут сохраняться и как долго

  • Локальные данные на устройстве: избранные рецепты, настройки, загруженный каталог и изображения остаются, пока пользователь сам не очистит хранилище или не удалит приложение и его данные. Разработчик не может удалить их дистанционно по письму.
  • Письма и обращения: хранятся на время рассмотрения и ответа; затем ненужные сведения удаляются. Если требуется исполнить законную обязанность, подтвердить рассмотрение обращения или защитить права при споре, необходимая часть переписки может сохраняться на соответствующий предусмотренный законом период. Единого фиксированного срока для всех обращений нет.
  • Публичные записи Стены меценатов: остаются в каталоге до исправления, удаления разработчиком или удовлетворения обоснованного запроса.
  • GitHub Pages: IP-адрес и сведения о сетевых запросах могут присутствовать в технических журналах провайдера в течение сроков, определяемых GitHub.
  • CloudTips: платёжные и связанные с ними сведения могут сохраняться у оператора платёжного сервиса по его правилам и требованиям закона.

Разработчик не может гарантировать удаление сведений из систем сторонних операторов по одному письму ему. Если часть данных необходимо сохранить, в ответе на запрос будет пояснено, что сохранено и почему, в пределах доступной информации.

4. Как самостоятельно удалить данные с устройства

Локальные данные не передаются разработчику через пользовательский аккаунт. Для удаления на Android откройте настройки телефона → «Приложения» → «Дошикология» → «Хранилище» → «Очистить данные» (названия разделов могут отличаться в зависимости от устройства). Можно также удалить приложение с очисткой его данных. В веб-версии очистите данные сайта в настройках браузера.

Будут удалены сохранённое избранное, параметры интерфейса, локально загруженные рецепты и изображения. Эти данные хранятся до очистки пользователем; отдельного автоматического срока удаления нет.

5. Обращения к внешним сервисам

При сетевых запросах инфраструктура GitHub Pages может обрабатывать технические данные подключения. Добровольная поддержка проекта ведёт на внешний платёжный сервис CloudTips, который обрабатывает платежи по собственным условиям. Разработчик не управляет журналами GitHub и платёжной базой CloudTips. Для запросов на удаление данных, находящихся исключительно у этих операторов, необходимо использовать их собственные каналы обращения.

Если вы обращались в поддержку по электронной почте, ваше сообщение может также сохраняться у поставщика почтовых услуг по его правилам. При удалении сведений из публичного каталога их обновление на устройствах других пользователей может зависеть от обновления локально скачанных копий.

6. Срок рассмотрения и другие права

Запрос рассматривается без необоснованной задержки, в сроки, установленные применимым законодательством. Если для исполнения запроса требуются дополнительные сведения или существует законное основание сохранить часть информации, разработчик сообщит об этом в ответе. Пользователь также может запросить доступную информацию об обработке своих данных, исправление, уточнение, блокирование либо отзыв согласия, если обработка основана на согласии.

Более подробное описание обработки и хранения сведений представлено в Политике конфиденциальности. Приложение доступно без регистрации и не создаёт аккаунтов пользователей.
