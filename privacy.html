Политика конфиденциальности

Приложение «Дошикология» и его веб-версия

Редакция от 12 ноября 2026 года

1. Кто отвечает за приложение

«Дошикология» — бесплатное приложение со справочником рецептов на основе лапши быстрого приготовления. Разработчик приложения — Роман Татабаев. Контакт для вопросов конфиденциальности и запросов об удалении данных: romantatabaev@gmail.com.

2. Данные, которые не требуется предоставлять

Для использования базовых функций не нужны регистрация, имя, номер телефона, адрес электронной почты, паспортные сведения или платёжные реквизиты. В текущей версии нет рекламных блоков, рекламных SDK, системы рекламного профилирования или отдельной аналитики действий пользователей. Если реклама появится в будущем, информация о ней и связанных с ней данных будет внесена в политику до включения рекламы.

3. Данные, хранящиеся на устройстве

Избранные рецепты, выбранный способ отображения списка рецептов и сохранённые контактные настройки могут храниться в локальном хранилище (localStorage). В Android-версии загруженные по запросу пользователя рецепты и изображения дополнительно могут сохраняться в IndexedDB для работы без сети. Для этих функций регистрация не требуется, и отдельная база учётных записей пользователей не ведётся.

Эти локальные данные не отправляются разработчику как содержимое пользовательского аккаунта. Они сохраняются на устройстве, пока пользователь не удалит данные приложения либо сайта или не удалит приложение (если операционная система удаляет его локальное хранилище). Автоматического срока удаления избранного и скачанных материалов нет.

Для удаления откройте настройки Android → «Приложения» → «Дошикология» → «Хранилище» → «Очистить данные» (названия пунктов могут отличаться на разных устройствах). Для веб-версии очистите данные сайта в настройках браузера. Это удалит избранное, настройки и загруженные материалы из локального хранилища. Запрос разработчику не даёт технического доступа к локальному хранилищу вашего устройства: его очистку нужно выполнить самостоятельно.

4. Сетевые подключения и технические сведения

В Android встроенные рецепты доступны без интернет-соединения. Проверка новых рецептов и загрузка выбранных дополнений выполняются по действию пользователя. При этом при запуске Android-приложения также может автоматически выполняться HTTPS-запрос к публичному файлу настроек на GitHub Pages для обновления адреса поддержки и ссылки добровольного пожертвования. В веб-версии ресурсы сайта загружаются при открытии страницы.

При сетевых обращениях к GitHub Pages поставщик инфраструктуры технически получает сведения о запросе — например, IP-адрес, сведения о браузере или устройстве и время обращения. Они используются инфраструктурой для доставки ресурса, безопасности и эксплуатации сервиса. Разработчик не ведёт собственной системы пользовательских профилей на основании этих запросов. Сроки хранения технических журналов определяются политиками GitHub; разработчик не может самостоятельно удалить такие записи из систем провайдера.

Сетевые адреса, предусмотренные текущим приложением для получения каталога и публичных настроек, используют HTTPS. Данные, введённые пользователем на внешних страницах после перехода по ссылке, обрабатываются соответствующими сервисами по их собственным правилам.

5. Добровольная поддержка проекта и отсутствие рекламы

В текущей версии нет встроенной рекламы и рекламных SDK. При добровольном нажатии кнопки поддержки открывается внешняя страница CloudTips. Приложение не запрашивает в собственном интерфейсе номер банковской карты и защитный код. На внешней странице сервис может обрабатывать платёжные и контактные сведения в соответствии со своими документами. В кабинете сервиса разработчику могут быть доступны сведения о переводе, в том числе сумма, дата и имя либо комментарий, если пользователь их указал.

Запросы на удаление данных, хранимых самим CloudTips, направляются оператору этого сервиса по предусмотренным им каналам. Разработчик может рассмотреть запрос относительно доступных ему сведений, но не управляет сроками хранения платёжных записей стороннего оператора.

6. Стена меценатов

Раздел может содержать имя или псевдоним, комментарий, дату и указанную сумму поддержки. В настоящий момент записи размещаются разработчиком через файл данных; открытой формы для самостоятельной публикации комментариев в приложении нет. Часть записей может быть демонстрационной и не служит подтверждением реального платежа.

Перед публикацией сведений о реальном человеке разработчик должен иметь необходимые законные основания и, когда требуется, отдельное согласие на распространение его персональных данных. Запросы об исправлении или удалении такой публикации принимаются по адресу romantatabaev@gmail.com.

7. Обращения в поддержку

Пользователь может добровольно отправить обращение через своё почтовое приложение. В таком случае разработчик получает адрес отправителя, текст письма и прикреплённые вложения, если они есть. Эти сведения необходимы для ответа и рассмотрения запроса; приложение не передаёт их автоматически при обычном использовании. Не отправляйте пароли или полные платёжные реквизиты.

Адрес поддержки: romantatabaev@gmail.com. Содержание обращений хранится на период рассмотрения запроса; после его завершения сведения, которые больше не нужны, подлежат удалению. Отдельные сообщения и относящиеся к ним сведения могут сохраняться дольше, если это необходимо для исполнения требований закона, защиты от претензий или подтверждения рассмотрения обращения. Срок зависит от соответствующего правового основания, универсального срока хранения для всех писем нет. Копии у почтового провайдера могут храниться по его правилам.

8. Хранение, удаление и безопасность сведений

Данные, оставшиеся только на устройстве (избранное, настройки и скачанный каталог), хранятся до их очистки пользователем; серверного аккаунта для удаления нет. Письма и обращения обрабатываются до достижения цели обращения и далее только при наличии законных оснований хранения. Публичные сведения на Стене меценатов размещаются разработчиком и сохраняются до их удаления или исправления; реальные сведения могут быть удалены по обоснованному запросу.

Технические журналы GitHub Pages и платёжные сведения CloudTips могут сохраняться по правилам соответствующих провайдеров. Запрос к разработчику не означает автоматического удаления данных из независимых систем третьих лиц. Разработчик не продаёт пользовательские данные.

Для предусмотренных приложением сетевых запросов используются адреса HTTPS, а информация, полученная по обращениям пользователей, не публикуется без соответствующего основания. При необходимости сведения в пределах контроля разработчика удаляются или исправляются по запросу с учётом применимого законодательства.

Подробная инструкция, перечень удаляемых и сохраняемых сведений и порядок обращения размещены на странице «Запрос на удаление данных».

9. Права пользователей и изменения политики

Пользователь может обратиться с вопросом о своих данных, запросить их уточнение, удаление, исправление либо сообщить об отзыве согласия, если обработка основана на согласии. Для этого напишите на romantatabaev@gmail.com. Чтобы узнать, как удалить локальные данные самостоятельно или запросить удаление сведений, которыми располагает разработчик, перейдите в раздел удаления данных. Запрос рассматривается в сроки, предусмотренные применимым законодательством. Если какие-либо сведения требуется сохранить, разработчик сообщит причину и применимые ограничения.

При изменении функций или обработки данных политика обновляется; актуальная дата редакции размещается в начале документа.
