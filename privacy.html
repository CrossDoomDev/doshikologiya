Приложение «Дошикология» и его веб-версия

Редакция от 13 октября 2026 года

1. Кто отвечает за приложение

«Дошикология» — бесплатное приложение со справочником рецептов на основе лапши быстрого приготовления. Разработчик приложения — Роман Татабаев. Контактный адрес для обращений: romantatabaev@gmail.com. Разработчик: Роман Татабаев.

2. Данные, которые не требуется предоставлять

Для использования базовых функций не нужны регистрация, имя, номер телефона, адрес электронной почты, паспортные сведения или платёжные реквизиты. В Android-обновлении версии 1.1.1 предусмотрен рекламный блок Рекламной сети Яндекса в режиме готовки. Используется Yandex Mobile Ads SDK, который может обрабатывать рекламный идентификатор устройства, IP-адрес и технические сведения для показа, измерения и защиты рекламы. Собственной системы регистрации и рекламного профилирования разработчик не создаёт. Перед включением персонализированной рекламы должно быть получено применимое согласие пользователя.

3. Данные на устройстве

Выбранные рецепты сохраняются в избранном через локальное хранилище устройства (localStorage). В Android-версии загруженные рецепты и изображения могут сохраняться локально через IndexedDB, чтобы быть доступными без интернета. Эти данные используются для работы приложения и не отправляются разработчику через отдельную систему учётных записей.

Локальные данные хранятся до их очистки пользователем, удаления приложения или данных сайта. Для их удаления можно очистить хранилище приложения в настройках Android либо данные сайта в браузере. Такая очистка также удалит сохранённое избранное и загруженные рецепты.

4. Сетевые подключения

Для открытия веб-версии, получения новых рецептов и изображений приложение может обращаться к GitHub Pages по адресу crossdoomdev.github.io/doshikologiya. При сетевом соединении поставщик инфраструктуры получает необходимые технические сведения (например, IP-адрес, характеристики браузера или устройства и время запроса). Порядок хранения таких журналов определяется правилами инфраструктуры GitHub, а не локальным хранилищем «Дошикологии».

В Android встроенные рецепты доступны без сети. Проверка и скачивание дополнений каталога выполняются по действию пользователя.

5. Добровольная поддержка проекта и реклама

Приложение бесплатно. В Android-версии 1.1.1 используется баннерная реклама Рекламной сети Яндекса в режиме готовки; в веб-версии рекламный SDK не подключён. При нажатии на кнопку добровольной поддержки открывается внешний платёжный сервис CloudTips. «Дошикология» не получает от пользователя в интерфейсе приложения номер банковской карты или её защитный код. Если пользователь добровольно совершает платёж, платёжные и контактные сведения обрабатываются внешним сервисом по его собственным документам; разработчику могут быть доступны сведения о пожертвовании, предусмотренные кабинетом сервиса (например, сумма, дата, имя или комментарий, если пользователь их указал). Перед вводом данных ознакомьтесь с условиями сервиса.

6. Стена меценатов

Раздел может содержать имя или псевдоним, комментарий, дату и указанную сумму поддержки. В настоящий момент записи размещаются разработчиком через файл данных; открытой формы для самостоятельной публикации комментариев в приложении нет. Часть записей может быть демонстрационной и не служит подтверждением реального платежа.

Перед публикацией сведений о реальном человеке разработчик должен иметь необходимые законные основания и, когда требуется, отдельное согласие на распространение его персональных данных. Запросы об исправлении или удалении такой публикации принимаются по адресу romantatabaev@gmail.com.

7. Обращения в поддержку

При обращении по электронной почте пользователь самостоятельно предоставляет адрес отправителя, содержание письма и, при желании, вложения. Эти сведения используются для рассмотрения обращения и ответа на него; они не публикуются в приложении. Не присылайте пароли и полные платёжные реквизиты.

Единственный канал пользовательских обращений: romantatabaev@gmail.com. Для запроса об удалении переписки или уточнении данных напишите на этот адрес; сведения удаляются после достижения цели обращения, если их дальнейшее хранение не требуется по закону. Переписка также может храниться у поставщика электронной почты по его правилам.

8. Передача, сроки и безопасность

Отдельная база учётных записей пользователей «Дошикологии» не используется. Передача сведений внешним провайдерам происходит при сетевых запросах, переходе к оплате или отправке обращения по электронной почте. Разработчик не продаёт пользовательские данные. Сроки хранения платёжных и технических сведений внешними сервисами определяются их документами; локальная информация остаётся до удаления пользователем, как описано выше.

9. Права пользователей и изменения политики

Пользователь вправе обратиться с вопросом об обработке его персональных данных, запросить уточнение или удаление сведений, если они находятся в распоряжении разработчика. Для этого можно написать на romantatabaev@gmail.com. При существенном изменении функций или способов обработки данных документ будет обновлён; дата актуальной редакции размещается в его начале.
