Политика конфиденциальности

Приложение «Дошикология» и его веб-версия

Редакция от 11 октября 2026 года

Предрелизный проект документа. До публикации в RuStore требуется указать подтверждённые данные разработчика и рабочий адрес для частных обращений. Текст необходимо повторно проверить перед публикацией.

1. Кто отвечает за приложение

«Дошикология» — бесплатное приложение со справочником рецептов на основе лапши быстрого приготовления. За работу приложения отвечает его разработчик. Юридические сведения о разработчике и электронная почта для обращений будут указаны в окончательной редакции до размещения приложения в RuStore.

2. Данные, которые не требуется предоставлять

Для использования базовых функций не нужны регистрация, имя, номер телефона, адрес электронной почты, паспортные сведения или платёжные реквизиты. В текущую версию приложения не встроена отдельная система рекламного профилирования или аналитики действий пользователей.

3. Данные на устройстве

Выбранные рецепты сохраняются в избранном через локальное хранилище устройства (localStorage). В Android-версии загруженные рецепты и изображения могут сохраняться локально через IndexedDB, чтобы быть доступными без интернета. Эти данные используются для работы приложения и не отправляются разработчику через отдельную систему учётных записей.

Локальные данные хранятся до их очистки пользователем, удаления приложения или данных сайта. Для их удаления можно очистить хранилище приложения в настройках Android либо данные сайта в браузере. Такая очистка также удалит сохранённое избранное и загруженные рецепты.

4. Сетевые подключения

Для открытия веб-версии, получения новых рецептов и изображений приложение может обращаться к GitHub Pages по адресу crossdoomdev.github.io/doshikologiya. При сетевом соединении поставщик инфраструктуры получает необходимые технические сведения (например, IP-адрес, характеристики браузера или устройства и время запроса). Порядок хранения таких журналов определяется правилами инфраструктуры GitHub, а не локальным хранилищем «Дошикологии».

В Android встроенные рецепты доступны без сети. Проверка и скачивание дополнений каталога выполняются по действию пользователя.

5. Добровольная поддержка проекта

При нажатии на кнопку поддержки открывается внешний платёжный сервис CloudTips. «Дошикология» не получает от пользователя в интерфейсе приложения номер банковской карты или её защитный код. Если пользователь добровольно совершает платёж, платёжные и контактные сведения обрабатываются внешним сервисом по его собственным документам. Перед вводом данных ознакомьтесь с условиями сервиса.

6. Стена меценатов

Раздел может содержать имя или псевдоним, комментарий, дату и указанную сумму поддержки. В настоящий момент записи размещаются разработчиком через файл данных; открытой формы для самостоятельной публикации комментариев в приложении нет. Часть записей может быть демонстрационной и не служит подтверждением реального платежа.

Перед публикацией сведений о реальном человеке разработчик должен иметь необходимые законные основания и, когда требуется, отдельное согласие на распространение его персональных данных. Запросы об исправлении или удалении такой публикации принимаются по контактному адресу разработчика, который будет указан перед выпуском приложения.

7. Обращения в поддержку

При отправке обращения по электронной почте или через внешний сервис пользователь самостоятельно выбирает, какие сведения предоставить. Они используются только для рассмотрения обращения и ответа на него в необходимом объёме и с соблюдением применимого законодательства.

В качестве временного публичного канала для технических замечаний доступен GitHub Issues. Публикуемые там сообщения видны другим людям. Не передавайте через него адреса, номера телефонов, финансовые, медицинские и иные конфиденциальные данные. Условия хранения и удаления публикаций в GitHub определяются правилами этого сервиса.

8. Передача, сроки и безопасность

Отдельная база учётных записей пользователей «Дошикологии» не используется. Передача сведений внешним провайдерам происходит при сетевых запросах, переходе к оплате или использовании внешней службы обращений. Разработчик не продаёт пользовательские данные. Сроки хранения информации внешними сервисами устанавливаются их документами; локальная информация остаётся до удаления пользователем, как описано выше.

9. Права пользователей и изменения политики

Пользователь вправе обратиться с вопросом об обработке его персональных данных, запросить уточнение или удаление сведений, если они находятся в распоряжении разработчика. Для этого до публикации будет указан отдельный контакт электронной почты. При существенном изменении функций или способов обработки данных документ будет обновлён; дата актуальной редакции размещается в его начале.
