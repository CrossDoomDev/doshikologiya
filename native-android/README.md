# Дошикология Kotlin preview 0.2.0

Независимое приложение на Kotlin и Jetpack Compose в `native-android/`; прежние HTML, CSS, JavaScript и Capacitor не меняются. Тестовый пакет: `ru.doshikologiya.nativepreview`.

Перенесены цвета, основной визуальный стиль, оригинальный логотип, экран-заставка, пять вкладок, карточки, меню выбора вида рецептов и режима готовки. 50 офлайн-рецептов и фото используются из `data/` и `images/`, без дублирования. Inline SDK демобаннер ограничен шириной до 280 dp.

Сборка `.github/workflows/native-kotlin.yml` публикует тестовую debug APK. Не публиковать её в RuStore: пока нет полного соответствия функциональности веб-приложения и миграции данных.


## 0.2.1: системные панели Android

В Activity включён единый режим обработки оконных областей Android (`WindowCompat.setDecorFitsSystemWindows(false)`), а корневой Compose-контейнер использует `safeDrawingPadding()` + `imePadding()`. Это оставляет строку состояния, нижнюю навигацию и вырезы экрана вне интерактивных элементов, не добавляя фиксированных отступов к каждой вкладке. Тёмный фон остаётся под системными панелями. Изменения только в `native-android/`.
