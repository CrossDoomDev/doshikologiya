# Дошикология: Kotlin preview 0.10.0

Нативное Android-приложение на Kotlin и Jetpack Compose. Эталон интерфейса и поведения — Capacitor в `main`; исходные JSON, фотографии, иллюстрации и тексты общие. WebView, JavaScript и рекламный SDK в нативной сборке не используются.

Тестовый пакет остаётся `ru.doshikologiya.nativepreview`: его можно установить рядом с опубликованной версией. Это не замена установленного Capacitor-приложения, его локальные данные между пакетами не переносятся.

## Сборка и проверки

Нужны JDK 17, Android SDK 35 и Gradle 8.11.1:

```sh
cd native-android
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Отчёты: `app/build/reports/`. Скриншоты тестовых телефонов: `app/build/parity-screenshots/`.

`CatalogParityTest` проверяет совместимость с опубликованным индексом, целостность и атомарную установку обновлений, сохранение старых данных при обрыве, публичные контакты, расчёт индекса Оракула и восстановление маршрутов. `NavigationParityTest` запускает Compose на Android API 34 через Robolectric: вкладки, три вида каталога, поиск, избранное, готовку, возврат, подтверждение выхода, Оракул и документы. Дополнительно проверяет экран шириной 320 dp. Это исполняемые проверки, а не поиск фрагментов кода в файлах.

GitHub Actions выполняет эти же проверки и публикует APK, отчёты и скриншоты в артефактах.

## Обновления и ссылки

Каталог открывается офлайн. Только кнопка проверки загружает `recipes-index.json`. После подтверждения скачиваются изменённые записи, проверяются UTF-16 FNV-1a хеши, затем изображения. JSON и фотографии публикуются одной атомарной сменой поколения. Ошибка загрузки оставляет прежний каталог доступным. Контакты поддержки и ссылка CloudTips обновляются отдельно при запуске и открытии «Ещё», как в Capacitor; проверяются только эти два поля.

Входящие URL `https://crossdoomdev.github.io/doshikologiya/?recipe=ID#recipes` обрабатываются при запуске и через `onNewIntent`. Это обычный HTTPS intent-filter, а не подтверждённые Android App Links: на Android 12+ автоматическое открытие требует настройки ссылок пользователем или доступного владельцу домена `assetlinks.json` с релизным сертификатом.

## Графика

Launcher-иконки сгенерированы из того же исходника и тем же алгоритмом, что в Capacitor. Чтобы пересоздать их после изменения оригинала, из корня репозитория:

```sh
npm install
node native-android/scripts/generate-icons.mjs
```

Полная карта сверки и границы проверки: [PARITY_AUDIT.md](PARITY_AUDIT.md). Сборка и Robolectric не являются сертификатом попиксельного совпадения на физическом устройстве.
