# Android-сборка Дошикологии

Сборка через бесплатный GitHub Actions и Capacitor 8.5.2.

## Установка на телефон
1. Открой GitHub → Actions → «Дошикология — Android APK».
2. Нажми Run workflow или открой успешный автоматический запуск.
3. Скачай архив doshikologiya-debug-apk из блока Artifacts.
4. Распакуй ZIP и установи app-debug.apk на телефоне.

Это тестовый APK (debug), подписанный отладочным сертификатом. Он не является готовым релизом RuStore. Для релиза понадобится постоянный ключ подписи под контролем владельца приложения. Нельзя публиковать ключи в репозитории.

## Офлайн-режим
Встроенные ресурсы, каталог и изображения попадают внутрь APK. **Автоматических сетевых проверок при запуске нет.** В разделе «Рецепты» пользователь вручную нажимает «Проверить обновления», затем при необходимости «Скачать рецепты»: приложение запрашивает индекс и докачивает только изменённые записи и изображения в IndexedDB. При отсутствии загруженной фотографии используется встроенное изображение. Автономность нужно дополнительно проверить на Android-устройстве.

Управляемый адрес проекта остаётся на бесплатном GitHub Pages. Собственный домен не требуется.

## Техническое устройство
Папка android/ создаётся внутри GitHub Actions командой npx cap add android и не сохраняется в репозитории. В дальнейшем для релиза понадобятся корректная иконка, versionCode, разрешения, целевой SDK, подпись и тестирование WebView.
