# Дошикология

Статическое веб-приложение «Институт дошикологии».

## Структура

- `index.html` — только разметка экранов приложения.
- `app.json` — рецепты, комментарии меценатов, ссылка CloudTips и версия данных.
- `css/styles.css` — визуальный стиль и адаптивность.
- `js/data.js` — резервные данные, конфигурация и состояние приложения.
- `js/core.js` — загрузка данных, общие помощники и главный рецепт.
- `js/recipes.js` — карточки, категории, поиск и фильтрация рецептов.
- `js/support.js` — Стена меценатов.
- `js/recipe-modal.js` — карточка рецепта, избранное и донаты.
- `js/cooking.js` — пошаговый режим готовки.
- `js/oracle.js` — Оракул и показатель дня.
- `js/router.js` — переходы между разделами.
- `js/app.js` — связывание событий и запуск приложения.
- `images/` — изображения рецептов, интерфейса и стикеры.

Изображения рецептов в `app.json` используют относительные пути, поэтому проект не зависит от имени GitHub-репозитория.

Ссылка CloudTips пока остаётся текущей и будет заменена отдельно после получения новой ссылки.
